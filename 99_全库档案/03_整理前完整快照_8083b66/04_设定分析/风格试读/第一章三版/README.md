## 怎么比较

[第一章三版精读比较（辅助评析，待作者判断）](第一章三版_精读比较_待审.md)：按人物声音、叙述与流程、地域语感、篇幅和阅读吸引力对照，引用与数字已核验；推荐是供选择的意见，不代替你的判断。

可以先对照三篇的开头、Eric通话和早餐，再通读最顺的一篇。重点看：

- 嘉弘像不像一个有自己判断的人，是否既肯帮忙又会不高兴？
- 哪种对白与叙述比例读起来舒服？有没有读到想跳过的部分？
- 你愿不愿意跟着这个声音继续读下去？

可以选整版，也可以指定“以A为底，Eric对话采用B的紧凑，早餐采用C的安静”。混合是重新编成一章，不是把三版的段落全叠在一起。选择风格后再调整第二章的声音，不会把男方的说话习惯套给林冬。
