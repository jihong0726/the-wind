## 证据标签

- **作者已确认**：明确选择的创作事实。
- **编辑采用**：在作者授权范围内选择的方案，和直接由作者确定的事实分开列。
- **旧稿明确或文本一致**：有正文或旧资料依据，但不自动等于当前确认。
- **冲突或缺桥**：版本不兼容，或缺少连接事件；保留相反证据，不补新剧情兜底。
- **推定**：由日期、事件或版本对应得出，不冒充原文明示。
- **建议或待选**：尚未批准，不进入正史。
- **待外部核验**：地理、制度、医学、行业或技术事实仍需相应来源确认。

旧资料的未来规划、角色的个人判断和客观世界规则分开处理。人物姓名、族裔、国籍、出生地、现住地及语言能力也分别登记。这里的健康、家庭和工作经历属于小说人物，不是作者或真实艺人的个人资料。
