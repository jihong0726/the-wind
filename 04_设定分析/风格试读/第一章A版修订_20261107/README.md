## 两处前后对照

### 从动作接力改为同一段心理

前稿：

阿豪挑了下眉。嘉弘低头拨开面上的青菜，又夹回来。他知道下一句多半是劝自己别做，可等了片刻，对面的人只是喝水。

本稿：

阿豪挑了下眉，嘉弘等着他劝自己别做，可对面没有接话，倒让他先忍不住解释：“这个我本来就想做好，要是技术那边有人愿意看，也不一定是坏事。”

删去拨菜、喝水的填充动作，让对方没接话这件事直接引出嘉弘的解释。

### 从起句说明改为循着线索查明问题

前稿：

嘉弘往上翻。机器人已经问了三次要不要联系骑手，客人也解释了三次饭在自己面前，最后才把照片发过来。

本稿：

嘉弘顺着照片往上翻，看见机器人已经问过三次要不要联系骑手，而客人每次都在解释饭就在自己面前，最后发来这一张图，又补了一句：“我讲的是这个没有，不是饭没有。”

照片、翻记录和客人的话围绕同一个误会展开，分类与退款操作随后承接，不再把每一步单独当作新的起点。
