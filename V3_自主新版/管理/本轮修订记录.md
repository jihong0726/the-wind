# V3 本轮修订记录

2026年11月7日。

本轮以仓库原始独立路线大纲为结构基础，旧大纲与V1、V2不改写、不删除。原大纲当前位于历史目录，保存其交付时的原貌；本目录中的《完整故事大纲》取代它成为V3当前写作依据。

已作的结构调整：

- 全部当前设定改用虚构组合SP4RK和四位虚构成员，重建年龄、职业和支线，不逐项映射真人生平。
- 体量目标改为约320万字级，分开报告纯汉字与含标点非空字符。按作者最新要求撤销单章字数硬下限，改为剧情节奏与实际投稿要求优先。12卷480章是初始容量结构，不是完稿声明。
- 四位成员各有独立目标、失误、选择与持续代价，写入十二卷，而非只安排围观恋情的戏份。
- 异地年度合作明确在相识第29至40个月履约，准备在第28个月结束，修正原月份不足一年的问题。
- 林冬第六卷的试演、失败、缩案与下一阶段合作者变化写入总纲，避免人物细纲与总纲出现两个互不相容的结果。
- 第五章才主动说明驻点四个月；第一章公开介绍不提前披露具体期限。第十一至十五章不再重复当成首次透露。
- 开篇三章采用独立事件：样件搬运受阻、排练选择及首封回信、现场追查和初识回信。没有继承V1/V2的开篇事件与既有关系。

机械校验与精读结论分别记录。长度和禁词通过不代表整部小说完成，也不能替代对场景、人物声音和后果的审阅。已完成正文清单与计数见本版本首页及《正文统计》。
