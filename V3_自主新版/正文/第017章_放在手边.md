# 第017章 放在手边

周三中午，林冬把饭盒往旁边挪，给流程纸让出一块干净地方。

上周四发来的工作参考已经换掉旧版。今天不连整场，只核月底现场那段串场的手势和下一首的入口，四个人要轮流站到房间后面看。林冬先吃完，替自己的那一句画了道线，笔尖停在句号后面。

手机就在纸旁边。她点开慢信，昨晚的两封还挨着。

暂住四楼写：“明天看新样。最近总在等，终于轮到拿东西试了。”

她回的是：“那等你回来讲。”

中午大概还早。她退出去，看了眼工作群里刚发的提示表，把手机塞进包侧袋。

刘敏从门外进来，正对着电话说，只能给对方到四点十分，再晚她就要走。挂断后，她问饭盒还有没有要留的，林冬把自己的盖好，两个人一起收进袋子。

地上标了两块区域，代替现场观众席。前几次排练的左右总有人看反，这回工作人员沿墙贴了两张大字，连房间最后面也看得见。纪小岚站到右边，弯腰看其中一个字。

“这个打印得像在让我向右逃生。”

“你先别逃。”刘敏说，“等我们唱完。”

今天没有人坐着假装观众。需要确认的很具体：谁带完句子，谁撤下手，轮接结束后由谁把两个方向接到一起。乐手也在，换完乐器便按提示等，不因她们试动作就自行往后走。

林冬站回自己的位置。

问候结束，刘敏带左边，纪小岚带右边。轮到两侧接唱，林冬朝左边摊开手，嘴里仍轻轻跟着，到了后半句，她习惯性地把话筒提近，将末尾的音送满。

“等一下。”站在后面的宁沐说。

她走到中间，模仿林冬刚才的样子，一只手请人唱，另一只手把话筒举到嘴边。

“我看着你，会觉得后面这几个字还是归你。”

林冬低头看自己的手。“我怕他们前面没跟上。”

“那你可以带前面。后面你还唱，我就继续听了。”

林冬想说自己声音不大，开口前又看了看离她最远的那张标牌。她站在这里，听得见自己的音量；坐在远处的人先看见的却是她把话筒举起来。

“再来一次。”她说。

第二次她撤得太快。句子没带完，手先放了下去，纪小岚在另一侧接早半拍，又自行停住。

林冬抬手：“是我，不是你。手早了。”

她走到流程纸边，在已经画线的句子中间添了一个小竖杠，没有改字。该领到哪里，领完后手留在哪里，她拿着话筒做了两次。不能一放下就像散场，也不用重新讲一遍。

第三次，她带完前面几个字，话筒退到胸前，摊开的手还朝着左侧。纪小岚接过右边的部分，刘敏在两个方向之间抬手，合唱第一遍进来，第二遍走完，再给乐手原定的提示。

下一首前奏响起时，没有人回头找谁。

宁沐从后面走回来，说这次看得懂。刘敏仍觉得合唱前转身有点急，自己留下来改那半步，没有要求大家把三分钟重新讨论一遍。

林冬在纸上记了“领前半，手不落”，把笔帽扣上。那首被舍掉的旧歌不在今天的纸里。她看着只剩几行的串场，还是觉得有点薄，翻到背面又是灯光和乐器提示，没什么可补的空白。

她将纸翻回来。

“我再去后面看一遍。”

这回宁沐替她站位。林冬站在门边，离开话筒和音响最近的地方，才发现四个人同时转向两侧时，中间会短暂空出来。她原本很想站回那个空处，可后排看过去，两边的手势因此更清楚。她没有叫停，只在音乐结束后告诉宁沐，刚才撤话筒的位置可以留下。

四点前，该核的几处都记了下来。郑允书收走修改标记，准备合进下一版提示表；刘敏赶自己的会，纪小岚戴上耳机去听另一份录音。林冬收好水瓶，发现手机被包带压在侧袋里，抽了两次才拿出来。

没有新信。

她看了一眼时间，觉得他那里也许还没做完。新样能不能用，哪有到中午就定下来的。她没有再往前翻，把手机放回去，出门买晚饭。

回家后，她先吃，吃完给饭盒沾油的边缘擦了一遍，才拿去分垃圾。厨房抽屉卡住了，拉开一点又顶回去。她蹲下把最下面那格抽出来，从背后捞出一张卷了边的纸。

不是她以为的保修单，是张饮料券。过期两个月，折痕刚好压住日期。她展开，看清赠的是小杯热饮，店名也已经想不起来。

她拿着券回到桌边，打开备忘录，写了两句话。

“今天修好一个抽屉，方法是拿掉一张过期的饮料券。已经不能喝了，我还是看了一眼能换什么。”

本来可以直接发。她读了一次，觉得接在新样后面有点突兀，又想等他来讲的时候再说。他讲完，她就有一件小事能接上，不用每次都问好不好、后来呢。

她将那两句话留在备忘录里，返回慢信。

仍是昨晚的两封。

她把手机放到桌子另一侧，去洗澡。头发吹到一半，热风把一缕碎发吹进眼睛，她关掉吹风机，用手拨开，忽然听见外面像有一下震动。出去看，是工作群的提示表。她放大自己负责的部分，确认刚才那条标记已经加上，回了收到。

走回浴室时，头发有一半凉了。她重新开机，风量比刚才小一档。

睡前她又看了一次，没有信。那张饮料券已经丢进废纸袋，两个句子还在。她把备忘录关掉，手机接上电，没将它带到枕边。

第二天上午，她出门前找了一会儿钥匙，原来被自己压在刚晒干的布袋下面。她掀开袋子，找到，又将布袋折了放回柜子，才出门。

周四的工作排得散，上午试服装，下午录几句需要补清楚的口播。录到最后一句时，工作人员让她把结尾再说轻一点，她录了三遍，自己挑第二遍，第三遍反而像提前松了气。等对方确认收齐，她才卸掉领口的小夹子。

中间的空当，她看过手机。午饭前一次，离开前一次。她没有数，直到晚上回家，打开慢信时，竟记得上一次屏幕的亮度比现在高。

她关上窗，在餐桌旁坐下。

九点还差几分钟。

昨晚那句“等你回来讲”被她看得有些别扭。当时就是顺着说的。他等新样等了那么久，终于有东西可试，她也想听。她没有问几点回来，他没说今天一定告诉她。

可她确实从昨天晚饭后就在留着一点时间。那两句饮料券的小事，一直没往别处放，像是只要发了别的，他要讲的新样就得跟在后面。

这也不是他让她留的。

她点进输入框，写“新样怎么样”，没发。问得太像等一个结果。他如果还没试完，就又得解释为什么没完。

她换成“今天很忙吗”，看了一会儿，觉得这句更容易让人只答忙。

桌边那张浅灰纸的一角翘起，她伸手按住，纸贴回墙面，过了几秒又离开一点。她拿杯子压住手边的流程纸，起身找胶带。补好墙角后，杯底留下一个很淡的圆印，她用指腹蹭了蹭，发现已经干了。

手机还亮着。输入框里的五个字没有消失。

她并不想问他为什么整天不看手机。她不知道他有没有看，也不想装作自己知道。也许回家已经很晚，也许还有别的事。她能随手想出几个理由，却没有一个能替他回这封信。

她删掉那五个字，写了一段。第一句是“没什么事”，看到这里，她自己先皱了眉。

没事为什么特地写这个。

她把第一句去掉，又删了最后的“算了”。这两句都像在等他问下去，删掉以后，她还是嫌语气有点硬。

九点零六分，她还是按了发送。

“你忙可以不回，但前天你说要看新样，我会等你回来讲。我不是要你现在讲完，就是想问一句，你还好吗？”

发出去后，她才发现“我会等”看起来还朝着以后。她想说的明明有一部分是昨天。

她没有再补第二封，把那张有杯底印的流程纸从桌上拿起来，放进明天要带的文件夹。纸边没有伸出去，拉链能合上。她合好，手机仍留在手边。
