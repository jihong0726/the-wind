## 第三、四章实际内容

- **第三章：** D0吉城，15:30醒来，洗衣、试换耳罩、买不到肉包、与父母通普通电话，回家煮面；原型界面改坏后退回旧版。21:10以后为22:00夜班留出准备时间，约21:15首配，昵称松果27／雨衣58。先听对方说一件反复做仍不满意的小事，再承认自己改坏过原来能用的东西，结尾停在对方问“那后来呢？”之后、他尚在输入时。
- **第四章：** 接着收到“换回原来那份了。还好没删。”，谈各自对结果的不满意、鸡肉饭团与没买到的肉包。林冬帮刘敏收东西，22:32主动晚安并结束聊天，对应吉城21:32，不影响男方21:45准备闹钟与22:00上班。次日与林夏聊灰色、墨绿色外套，按原定团体安排带短靴出门，未再打开树洞。

## 第二章实际内容

同一开篇故事日，2026年4月、守城，下午录制至夜间宿舍。林冬上午自行练习录音的事以回想带入，未另立日期。

- 短靴使跨步缩小、换气推迟。林冬借回放定位问题，和刘敏、编舞及摄影协调走位，完成声音满意的一条；结尾因松了口气而笑早，仍决定采用。
- 刘敏兼顾全队与自己的镜头，林冬陪她确认回放；宁沐与纪小岚也说出自己想保留的表演。休息时聊电影，宿舍聊小说，四人的偏好和意见各有不同。
- 收工在便利店补牙膏，林冬选焦糖布丁，放弃另买热饮；把仅剩的鲔鱼饭团让给宁沐，自己吃鸡肉口味，觉得酱偏甜。这是可支配资金的取舍，不增写家庭贫困、债务或收入数额。
- 回宿舍卸妆洗澡、吃布丁并与队友聊小说。宁沐留水的纸条仍写“温的。现在可能不温了。”林冬给她留勺子，并发消息夸布丁，本章不再反复描写喝水。
